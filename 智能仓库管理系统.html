📐 主程序流程 & 模块调用关系图

🔁 主程序流程概述：
1️⃣ 页面加载 → DOMContentLoaded 触发初始化入口 → 加载 localStorage 数据 → 初始化界面选项卡 (导航/查询/盘点) → 绑定表单/按钮事件。
2️⃣ 用户交互：
  • 入库/出库/调拨 → 验证数据 → 更新内存数组 → 持久化(localStorage) → 反馈消息。
  • 查询(精准/分类/预警) → 过滤数据 → 动态渲染表格。
  • 盘点(全量/分类) → 统计总重/体积/数量 → 展示报表。
  • 数据清理 → 过滤过期且零库存记录 → 保存并提示。
  • 文件导入/导出 → CSV解析/生成 → 批量操作。
3️⃣ 核心模块分层：UI控制层(事件绑定) → 业务逻辑层(Handle系列) → 数据持久层(saveToLocalStorage/loadFromLocalStorage) + 消息层(showMessage)。
🗂️ 函数调用层级说明：
• 初始化入口 (DOMContentLoaded) → 调用 initTabs, initQueryTabs, initInventoryTabs, initFormSubmissions, initButtonClicks, loadFromLocalStorage。
• 事件注册函数 (initFormSubmissions) 将表单提交绑定至 handleInbound / handleOutbound / handleTransfer / handlePreciseQuery / handleCategoryQuery / handleWarningQuery。
• 数据变更函数 (入库/出库/调拨/清理/导入) 最终调用 saveToLocalStorage 和 showMessage；导出调用 showMessage。
• 盘点 由 initInventoryTabs 绑定 performFullInventory / performCategoryInventory，直接读取 goodsArray 渲染。
• 工具层 (saveToLocalStorage, loadFromLocalStorage, showMessage) 为全局复用模块。
